Typography

Font controls for each section of the site. Every field is optional — anything left blank keeps the existing design untouched. Changes apply live and are published to Supabase with Save changes.

Global Design

Named colours and text styles that Page Builder sections and elements can point at, so one change here moves every element that uses them. These affect the Page Builder only — nothing here repaints the navigation, the odds table or the footer.

Several roles already exist on this site and are taken straight from Colors, which stays their home. Change one there and it changes here too. Override a role below only when you want the Page Builder to differ from the rest of the site.

Footer description

The paragraph under the site name in the footer's first column. This is the same value as Texts › Footer description — editing it here edits it there.

Navigation columns 0

Drag a column or a link by its handle to reorder. Untick to hide one without deleting it. At most 6 columns and 12 links per column — the footer is navigation, not a link farm.

The Brand and Support columns are not listed here. They hold the logo, site name, social icons and the WhatsApp link, and stay exactly as they are.

Copyright

The line at the very bottom. Same value as Texts › Footer copyright.

What visitors see without JavaScript

Every page ships with a footer already written into its HTML, and that is what search engines read. The columns above replace it only when they are valid. If this panel is emptied, or the saved data is unreadable, the shipped footer stays on the page — so the site never loses its internal links. To change what ships, edit FOOTER_GROUPS in tools/build-shell.js and run node tools/build-shell.js.

SEO

Everything here is stored in the same config as the rest of the CMS and published with Save changes. Fields left blank fall back to what the page's HTML already contains, so an empty field never blanks a page.

Every page at a glance

Checks run against what is saved right now. They are editorial guidance, not a score — search engines do not publish one.

Site identity

The base URL is used to build every canonical and og:url. Change it only if the site moves to a different domain.

Default title & description

Used by any page that has no title or description of its own.

Search engine verification

Paste the content value from Search Console, Bing Webmaster Tools or Yandex. A tag is written into the page only when its field has a value — empty fields output nothing at all.

Sharing defaults

What social platforms show when someone shares a link. Pages can override any of it individually. X/Twitter falls back to the Open Graph values, so you only fill the X fields in when you want something different there.

Default share image

A real image around 1200×630. Leave it blank until one exists — no tag at all is better than a tag pointing at a missing file.

Organization

Describes the site owner to search engines. Only fields you fill in are published — nothing is invented, and empty values are simply omitted.

Social profile URLs sameAs

One real profile URL per line. Only add profiles that genuinely belong to this site.

What gets published

Per-page WebPage, ContactPage and breadcrumb markup is switched on in Pages, next to the page it belongs to. Breadcrumb markup is only emitted when the page actually shows a breadcrumb.
